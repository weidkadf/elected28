# 2020→2024 법정 구역문구 검토 목록

2026-10-17, 2020년 253개·2024년 254개 법정 선거구 구역행을 PDF 표 셀에서 전부 추출했습니다. 시도별 구역수와 총수가 원문 머리말에 일치하고, 시도·선거구명은 각 선거 공식 득표 파일의 전체 키 집합과 일치합니다. 강원도/강원특별자치도, 전라북도/전북특별자치도 이름만 대응하며 경계 동일성을 가정하지 않습니다.

2024년 254개 기준 검토 상태:

| 상태 | 수 | 의미 |
|---|---:|---|
| 동일 명칭·구역문구 동일 | 171 | 공백·가운뎃점 표기만 정규화한 문구가 같음. 지리/행정 경계 동일성은 미검증 |
| 동일 명칭·구역문구 차이 | 61 | 재획정 외에도 행정동 분할·통합·명칭 변경일 수 있으므로 개별 확인 필요 |
| 동일 명칭의 2020 전신 없음 | 22 | 동일 이름 키가 없는 것이며 전신 지리가 없거나 완전히 새로 생겼다는 뜻이 아님 |

아직 득표 변환표가 아닙니다. 모든 행은 `crosswalk_eligible=false`, `vote_transfer_weight=null`입니다. 동일 문구만 보고 2020 득표를 2024 선거구에 이전하거나 면적·인구·정당별 가중치를 만들지 않습니다. 이 작업은 21대→22대 백테스트의 지리 정렬 준비이며 23대 획정 확정과 무관합니다.

- `source_manifest.json`: 국가법령정보센터 원문 URL·법률 개정일·PDF 해시. 재생성된 PDF 메타데이터 날짜를 과거 시점 공개일로 사용하지 않습니다.
- `statutory_district_rows.json`: 두 해의 구역행 원문, 페이지/표/행 좌표, 비교용 문자열.
- `boundary_review_254.json`: 현 모델 district_id로 연결한 254개 검토 상태, 같은 명칭의 2020 행.
- `boundary_inventory_report.json`: 253/254 완전성, 비교 상태 합계, 파서 및 원문 해시.
- `outputs/boundary_case_audit_20261017_0250.json`: 강동·사하·노원의 원본 PDF 독립 점검(프로젝트 루트 기준).

재현: 선택 의존성 `requirements-boundary.txt`를 설치하고 프로젝트 루트에서 `python scripts/build_boundary_inventory.py`, `python -m unittest test_boundary_inventory.py` 실행. 현 모델 계산에는 numpy만 필요하며 새 PDF 파서는 계산 엔진 입력 경로와 분리되어 있습니다.
