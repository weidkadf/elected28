# 2020 공식 자료 — 원경계 지역구 합계 대조 완료

## 현재 상태 — 0.2.2

`crosscheck_official_tables.py`로 별도 선관위 ZIP의 지역구 XLSX 329개를 읽어 시군구 분할을 합산했습니다. 복구 CSV와 253구·1,101 후보 레이블의 정당/성명/득표·유효표·당선자 및 선거인/투표/무효/기권 합계가 모두 일치합니다. 비례 250개·재보궐 56개 장표는 제외했습니다. 같은 선관위의 다른 공개 형식 대조이며 독립 재검표가 아닙니다.

- 전지역 판정: `independent_crosscheck_report.json`
- 장표별 식별정보·후보표·합계·해시: `official_table_manifest.json`
- 검증된 원경계 자료: `verified_candidates_2020.csv`
- 재현: `python data/history_2020/crosscheck_official_tables.py`
- 검사: `python -m unittest discover -s data/history_2020 -p test_crosscheck.py`

원본 CSV/ZIP과 기존 QUARANTINED 파일 및 당시 reconstruction_report는 이력으로 보존했습니다. 현재 검증 상태는 최신 independent_crosscheck_report를 따릅니다. 등록/사퇴 후보 전체 명부 또는 투표구별 전수 대조를 완료했다고 주장하지 않습니다.

`historical_district_totals_verified=true`이지만 2020↔2024 경계 변환·후보/정당 매핑·과거 조사와 백테스트가 남아 `model_eligible=false`입니다. 현행 모델에는 아직 연결하지 않습니다.

## 아래는 복구·검증 전 단계의 기록

2026-10-16 중앙선거관리위원회가 공공데이터포털에 공개한 제21대 총선 CSV 원문을 확보했다. 원문은 17,774,982바이트, 데이터 289,980행, 253개 지역구를 포함한다.

**모델·백테스트 입력에 사용하면 안 된다.** 원문의 후보자 열에 종로구 후보 이름이 다른 지역에도 반복되고, 실제 해당 지역 후보 이름이 득표수 열에 문자열로 들어 있다. 비숫자 득표수 2,772행(비어 있지 않은 값 1,090행)을 확인했다. 단순 집계하면 후보와 정당이 잘못 배정된다.

예: 중구성동구갑 행의 `후보자=더불어민주당 이낙연`, `득표수=더불어민주당 홍익표`. 타지역 수치에도 종로구 후보 이름이 붙는다. 원문을 보존했고 임의 수정이나 모델 투입은 하지 않았다.

- 원본: `nec_2020_raw.csv` (CP949)
- 다운로드 URL·SHA256·문제 사례: `source_quality_report.json`
- 재검사: `python inspect_source.py`
- 공식 목록: https://www.data.go.kr/data/15025527/fileData.do
- 공식 XLSX 대안: https://data.nec.go.kr/open-data/file.do?dataId=9 (이번 접속은 타임아웃/502)

다음 작업은 다른 공식 XLSX 원본 확보와 교차 검증이다. 복구가 필요하면 지역구별 삽입 헤더를 해석하고 후보명·유효표·당선자를 독립적으로 확인해야 한다. 2020년 253개 지역구와 2024년 254개 지역구는 이름만으로 연결하지 말고 경계변경표를 별도로 확보해야 한다.

## 2026-10-16 후속 진단: 구조 복구, 독립 검증 대기

`reconstruct_quarantined.py`에서 15행 고정 슬롯 구조를 재현 가능하게 해석했다. 원본의 `후보자` 열은 모든 지역에서 종로구 후보명을 그대로 둔 열 슬롯이다. 종로 이외 252개 지역구 시작의 15행은 실제 투표행이 아니라 새 후보명을 담은 헤더이며, 11개 후보 칸 중 빈칸을 포함하여 252×11=2,772행이 비숫자 오류를 정확히 설명한다. 후보 슬롯은 지역구 시작 헤더의 정당·후보명으로 다시 대응한다. 헤더에 남아 있는 `잘못 투입·구분된 투표지`라는 읍면동 값만 보고 수치 투표행으로 취급해서는 안 된다.

검사 결과:
- 253개 지역구, 1,101개 **원문에서 재구성한 후보 레이블**. 등록 후보 수와 동일하다고 주장하지 않는다.
- 헤더 제외 19,080개 수치 블록 전부 `후보득표합+무효표=투표수`, `투표수+기권수=선거인수` 통과.
- 이름이 빈 슬롯의 비영(非零) 득표는 0개. 헤더·순서·중복·음수표 검사 통과.
- 원본 SHA256 불변. 모델 파일은 변경하지 않았다.
- 재구성 의석은 더불어민주당 163, 미래통합당 84, 정의당 1, 무소속 5로 선관위 사이버선거역사관의 전국 집계와 일치한다. **이 전국 합계 확인은 253개 지역별 후보·득표 독립 검증을 대신하지 않는다.**

실행: `python data/history_2020/reconstruct_quarantined.py` (프로젝트 루트에서)

생성물은 이름에 `QUARANTINED`를 명시했다. `reconstruction_report.json`의 `model_eligible`은 `false`다. **학습·보정·백테스트 입력은 여전히 금지**한다.
