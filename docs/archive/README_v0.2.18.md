## 연동 방식

1. 22대 총선 실제 지역구 득표를 출발점으로 둡니다.
2. 2024년 정부지원·견제 응답과 현재 응답을 당시 여야 지위에 맞춰 같은 정당 방향으로 정렬합니다.
3. 전국 변화와 권역별 차이를 계산합니다. 권역 소표본은 전국 방향 쪽으로 축소하고, 강원·제주처럼 공개되지 않은 값은 전국 대체 사용 여부를 표시합니다.
4. 이 변화가 지역구 득표에 반영되는 강도를 여러 계수로 계산합니다. 계수와 오차 규모는 아직 검증 전 가정입니다.
5. 민주·국힘이 함께 출마한 2024 지역구에서는 두 당 합계 득표를 보존하면서 두 당 사이 비율을 움직입니다. 제3후보 표를 고정하는 것도 조건부 가정으로 표시합니다. 한쪽이 출마하지 않은 지역은 결과를 만들어내지 않고 보류합니다.

- `data/events.json`: 확인된 재보선 등 사건 기록(전체 현역 명부가 아님)
- `BACKLOG.md`: 다음 개발·검증 작업
- `UPDATE_PROTOCOL.md`: 반복 갱신과 서브에이전트 분업 규칙

## 재현

Python 3.10 이상과 numpy가 필요합니다. 프로젝트 폴더에서 실행합니다.

```bash
python -m pip install -r requirements.txt
python -m unittest test_model.py test_safety_guards.py
python -m unittest discover -s data/history_2020 -p test_crosscheck.py
mkdir -p outputs
python model.py --baseline data/baseline_2024.csv --polls data/polls.json --frame-comparison config/frame_comparison.json --output outputs/model_report.json --draws 5000 --seed 20261016
python scripts/render_summary.py
```

비교 계수, 전국/지역/개별 지역구 오차 규모는 가정입니다. 자세한 값은 `config/frame_comparison.json`에 명시되어 있습니다. 같은 입력과 시드를 사용하면 같은 결과를 재현할 수 있습니다. 실제 검증 전 오차 규모를 신뢰구간으로 표현하지 않습니다.

## 데이터 구조

- `data/raw/nec_2024.csv`: 원본 공식 개표 CSV, 보존
- `data/baseline_2024.csv`: 후보별 득표. `valid_votes`는 지역구 합계의 반복값이므로 후보행 기준으로 합산하지 않습니다.
- `data/districts_2024.csv`: 지역구별 당선인·2위·득표차
- `data/polls.json`: 질문 종류·조사기간·표본·출처를 구별한 조사 관측
- `config/frame_comparison.json`: 정부지원·견제 비교 조사, 시점별 여야 지위와 감도 실험 가정
- `scripts/build_baseline.py`: 원자료 집계 재현 스크립트

2024년 행정구역·선거구명은 역사적 기준입니다. 2028년 획정이 확정되면 읍면동 자료와 경계 변환표를 사용해야 합니다. 현재 `district_id`는 프로젝트 내부 식별자이며 선관위 공식 코드가 아닙니다.

## 지속 갱신

예약 실행은 새 정부지원·견제 여론조사와 후보·선거구 변화를 확인하고, 미완료 검증 작업을 이어갑니다. 가능한 실행에서는 자료·정치 변화·검증을 서브에이전트에 분담합니다. 상시 프로세스 유지에 의존하지 않고 이 프로젝트의 최신 저장 상태에서 재개합니다. 새로운 근거가 없으면 결과 숫자를 임의로 갱신하지 않습니다.

## 0.2.1 검증 갱신 — 2026-10-16

정부지원·견제 조사에 발표일을 필수로 요구하고, 자료 기준일 이후 발표된 조사를 거부합니다. 2024 기준 조사는 전국·권역 모두 선거일 이전 발표 자료만 허용합니다. 현재는 날짜 단위 검사이므로 같은 날의 발표시각에 대한 누출 방지는 별도 과제입니다.

13개 단위검사와 전국 254개 지역구 실제 입력 검증을 통과했습니다. 정당지지도 레코드를 삭제하거나 수치·날짜를 극단적으로 바꿔도 출력 전체가 같고, 동일 시드 결과가 재현됩니다. 코드 변경 후 재산출한 주간·월간 기준 시나리오 수치는 기존과 같습니다. 245개 조건부 계산·9개 보류이며 검증된 당선확률은 아닙니다.

2020 CSV의 삽입 후보명 머리글을 해석해 253개 지역구·1,101개 후보 레이블을 복구했습니다. 19,080개 수치 블록의 투표·선거인 합계는 모두 일치합니다. 별도 선관위 원본 ZIP을 확보했지만 253개 지역별 독립 대조는 미완료이므로 복구본은 계속 격리하며 학습·백테스트에 쓰지 않습니다.

검증 기록: `outputs/update_validation_20261016.json`. 조사 확인: `outputs/research_check_20261016_1530.json`. 후보 변화는 `outputs/candidate_check_20261016_1530.json`에 근거 수준별로 보존했으며 미확정 후보나 당별 표 배분은 생성하지 않았습니다.
