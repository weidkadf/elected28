검증된 예측이 아닙니다. “현재의 정부 지원·견제 여론이 선거일까지 유지된다면”이라는 조건의 시나리오입니다. 2024년 선거구를 그대로 썼고 후보는 반영하지 않았습니다. 비례 46석은 간이 계산입니다.

방법

  • 출발점: 지역구 성향 = 2024 총선 0.5 + 2025 대선 0.3 + 2026 시도지사 0.2 (읍면동 개표를 2024 선거구에 배정).
  • 여론: “정부 지원 vs 견제” 문항의 2024년 → 현재 변화를 권역별로 집계. 최신성 반감기, 기관 단위 가중, 조사방식 품질가중, 투표 의향 보정을 적용.
  • 전이: 지역구 득표 logit = 출발점 + α × 여론 변화 + 전국·권역·지역구 오차. 전국 오차는 선거까지 남은 날의 제곱근에 비례해 커짐.
  • 비례: 2024년 비례 득표율에서 출발해 같은 여론 변화를 적용, 3% 봉쇄조항·병립형 배분. 범민주 비례표를 민주·조국혁신당으로 나누는 비율은 기본이 2024년 득표비이고, 여심위 등록 전국 정당지지도로 만든 두 값을 선택할 수 있음(이 선택은 민주·조국 사이 배분만 바꾸고 범민주 대 국민의힘 의석은 그대로). 개혁신당 득표율도 기본은 2024년 값(3.61%)이고 같은 방식으로 만든 두 값을 고를 수 있음.
